Student Management System

A simple Student Management System built using Python. This project allows users to add student details, view student records, and exit the application through a simple menu-driven interface.

Features

•⁠  ⁠Add student details
•⁠  ⁠Store student name, roll number, and course
•⁠  ⁠View all student records
•⁠  ⁠Display a message when no students are available
•⁠  ⁠Simple menu-driven interface

Technologies Used

•⁠  ⁠Python
•⁠  ⁠Lists
•⁠  ⁠Dictionaries
•⁠  ⁠Loops
•⁠  ⁠Conditional Statements
•⁠  ⁠User Input

How to Run

1.⁠ ⁠Make sure Python is installed on your computer.
2.⁠ ⁠Download or clone this repository.
3.⁠ ⁠Open the project folder in VS Code or Terminal.
4.⁠ ⁠Run the following command:

python3 main.py

5.⁠ ⁠Select an option from the menu.

Menu

1.⁠ ⁠Add Student
2.⁠ ⁠View Students
3.⁠ ⁠Exit

Project Purpose

This project was created to practice Python programming fundamentals and understand how a simple menu-driven application works.
